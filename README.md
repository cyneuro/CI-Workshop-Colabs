# Colabs for the CI Workshop

Google Colab notebooks for **Scientific Workflows for Brain and Behavioral Research**, a two-day remote workshop supported by the National Science Foundation (Award No. OAC-2417875), University of Missouri. Next offering: **January 14–15, 2027**.

**Workshop website:** <https://019f883f-d93e-21a6-f811-ae2939c5175d.share.connect.posit.cloud/>. Start there: each notebook has a video walkthrough and a lab manual, and the site explains the order to work through them.

No programming experience is needed. Every notebook uses the same four-step cycle with an AI assistant: **Ask → Check → Build → Document**. Check what the AI gives you before you run it, and never paste identifiable participant data, passwords or access keys into a public AI tool.
